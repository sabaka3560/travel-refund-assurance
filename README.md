# Travel Refund Assurance

Audits airline cancellations an enterprise has already made: it reconstructs the refund the passenger was **owed** under
the fare rules in force at booking and cancellation time (and DGCA limits), compares it with the refund actually received,
and shows the evidence behind every rupee.

Proof of concept by [Tanmay Bohra](https://tanmaybohra.com). Indian domestic carriers (SpiceJet, IndiGo, Air India,
Air India Express, Akasa).

## Why it can be trusted

- **No LLM in the calculation path.** Deterministic Python over integer paise and integer-second intervals.
- **Evidence-backed rules.** Every fare rule points to a preserved copy of the airline's own policy page
  (`engine/corpus/evidence/<sha256>`, captured from the Internet Archive). Hashes are re-checked at load time; a rule whose
  evidence is missing or altered is quarantined and can't reach a ledger line.
- **Honest about gaps.** Each rule records what its evidence does and doesn't prove; unsupported cases (reissued tickets,
  multi-passenger, corporate fares) are refused instead of guessed.

## Run the demo

```bash
python start_demo.py            # checks dependencies, starts the console at http://127.0.0.1:8000
```

Upload a ticket from `demo_uploads/` (synthetic tickets, generated by `demo_uploads/_generate.py`) and pick a cancellation time.

## Check it

```bash
pip install -r server/requirements.txt pytest
pytest engine/tests -q                 # engine test suite
python engine/tools/run_benchmark.py   # exact matches on the positive set, zero false confidence on the negative set
python engine/tools/corpus_lint.py     # corpus integrity
```

## Layout

- `engine/` — the refund reconstruction engine, rule corpus and evidence store (details in `engine/README.md`)
- `server/` — FastAPI backend and single-page console (API in `server/README.md`)
- `benchmark/` — positive and negative benchmark cases
- `demo_uploads/` — synthetic sample tickets
